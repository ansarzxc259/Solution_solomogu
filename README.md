# Soup Kernel Challenge: fused RMSNorm

## Что сделано
Свой Triton-кернел fused RMSNorm (прямой и обратный проход) для
Qwen2RMSNorm. Он заменяет цепочку мелких операций с приведением в fp32
одним кернелом и хранит для backward только вход (fp16) и rstd, а не
fp32-копии активаций. Подключается через solution.apply().
Рядом работает пример swiglu из стартового набора.
Идеи: стандартная схема fused RMSNorm из документации Triton
(указать источник, если смотрели).
